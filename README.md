# taskToTime
## 📅 *О проекте*
Это десктопное приложение для ежедневного планирования с поддержкой повторяющихся задач, учётом выполнения и сменой темы. Данные хранятся в PostgreSQL, интерфейс построен на WPF и XAML.

## 🛠 *Технологии*
- C# + .NET 6 (и новее)
- WPF ((Windows Presentation Foundation)) + XAML
- PostgreSQL 14+

## ✨ *Возможности*
Программа содержит следующие функции:
- 🔐Регистрация / авторизация пользователей
- 🌓 Смена светлой / темной темы приложения
- 📆 Создание **постоянных** задач(на выбранные дни недели)
- 🔁 Создание **повторяющихся** задач
- ✅ Отметка выполнения задач
- 🗄Все данные хранятся в PostgreSQL

## 📦 *Установка и запуск*
- Создать базу данных postgreSQL и выполнить скрипт:
``` postgresql
CREATE TABLE users (
id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
login TEXT NOT NULL UNIQUE,
mail TEXT NOT NULL UNIQUE,
password TEXT NOT NULL
);

create table tasks (
id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY key,
user_id INTEGER not null,
name_task TEXT not null,
description TEXT,
appointment_day TIMESTAMP not null,
completed bool default false,
permanent bool default false,
recurring_days TEXT,
month DATE,
excluded_dates TEXT,
foreign key (user_id) references users(id)
);

CREATE TABLE task_completions (
id INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
task_id INTEGER NOT NULL REFERENCES tasks(id) ON DELETE CASCADE,
completion_date DATE NOT NULL,
UNIQUE(task_id, completion_date)
);
```
- В файле DataBase.cs поменять строку подключения:
```cs
private string connectionString = "Server=/*localhost*/; port=/*5432*/; Database=/*Название вашей БД*/; User Id=/*Логин*/; Password=/*Пароль*/;";
```
- Открыть `.sln` и запустить в Visual Studio, либо `dotnet run`

## 🚀 *Использование*
1. Зарегистрируйтесь или войдите в существующий аккаунт.
2. На главном экране нажмите «Добавить задачу».
3. Для повторяющейся задачи отметьте дни недели и укажите период.
4. Выполненные задачи отмечайте галочкой – запись о выполнении сохранится в таблицу `task_completions`.
5. Переключайте тему через пункт меню «Настройки».
6. Нажмите на кнопку "Календарь" - перейдете в календарь со всеми задачами
